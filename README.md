# Woodhouse 2.0

The refreshed **Woodhouse** wedding-photographer template by GlowUp Online (Squarespace + Showit, sold on Etsy). Editorial and premium, with the romantic scrapbook / film / heirloom personality of the original. Demo persona: Emma Woodhouse, Austin, TX.

These HTML pages are the design source. The final design is polished in Wonder and rebuilt by hand in Showit and Squarespace.

## Preview
```bash
npx serve .
```
Then open `/pages/home`. The floating Desktop / Mobile toggle switches to a 390px mobile layout.

## Folders
- `assets/` — photos and graphics (`assets/wonder/` holds images originally hosted in Wonder)
- `fonts/` — licensed brand fonts (IvyPresto, Thesignature, Fino Sans). Check the web-embedding license before publishing publicly.
- `docs/` — project history and decisions
- `design inspo/` — reference images only

See `CLAUDE.md` for the full brand system and build notes.
